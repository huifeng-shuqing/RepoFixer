    Fix ancestor exclusion checks after gitignore negations
    
    Check strict ancestors even when the last directory match is a negation
    or the matching pattern has no directory marker. Return the excluding
    ancestor's pattern index consistently across Simple, RE2, and Hyperscan.
    
    Cover nested directory exceptions, terminal globstars, batch filtering,
    re-inclusion controls, and bounded ancestor matching in regression tests.
